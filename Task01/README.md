# Task 01: Подготовка данных и знакомство с SQLite

В данной директории (`Task01`) находятся исходные файлы набора данных (формат, аналогичный MovieLens) и результаты выполнения первого задания.

## Описание структуры файлов данных

### Исходные данные (Dataset)
- **`ratings.csv`** — основной файл с оценками пользователей.  
  Содержит столбцы: `userId` (идентификатор пользователя), `movieId` (идентификатор фильма), `rating` (оценка), `timestamp` (временная метка).
- **`movies.csv`** — справочник фильмов.  
  Содержит столбцы: `movieId`, `title` (название фильма и год выпуска), `genres` (жанры, разделенные символом `|`).
- **`tags.csv`** — пользовательские теги, добавленные к фильмам.  
  Содержит столбцы: `userId`, `movieId`, `tag` (текстовый тег), `timestamp`.
- **`users.txt`** — справочник пользователей. Файл имеет формат с разделителем `|`.  
  Содержит поля: `userId`, `Имя`, `Email`, `Пол`, `Дата` (регистрации/рождения), `Профессия` (occupation).
- **`occupation.txt`** и **`genres.txt`** — дополнительные справочные файлы со списками возможных профессий и жанров (при наличии в полном наборе данных).

### Файлы, созданные в ходе выполнения задания
- **`ratings_count.txt`** — результат анализа файла `ratings.csv`. Содержит две строки:  
  1. Минимальный `userId` и количество строк с этим идентификатором.  
  2. Максимальный `userId` и количество строк с этим идентификатором.
- **`sqlite.txt`** — отчет о работе с СУБД. Содержит номер установленной версии SQLite и список режимов вывода данных, доступных в консольной утилите `sqlite3`.
