Версия SQLite: 3.53.4

Режимы вывода данных в утилите sqlite3:
- list      - значения через разделитель (по умолчанию |)
- column    - выровненные колонки
- table     - ASCII-таблица с границами
- box       - таблица с Unicode-рамками
- csv       - формат CSV (через запятую)
- html      - HTML-таблица
- json      - формат JSON
- markdown  - Markdown-таблица
- insert    - SQL-команды INSERT
- line      - каждое поле на новой строке
- tabs      - значения через табуляцию
- tcl       - Tcl-список
- quote     - значения как SQL-строки
- ascii     - ASCII-разделители
